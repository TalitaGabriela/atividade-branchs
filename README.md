# Atividade Branchs

Projeto de exemplo para praticar branches, merges e pull requests no Git/GitHub.

## Funcionalidades

1. Contador de cliques
2. Modo escuro
3. Formulário de contato
4. Validação do formulário
5. Lista de tarefas
6. Busca/filtro de tarefas

## Fluxo de branches

Cada funcionalidade foi desenvolvida em uma branch própria (`feature/nome-da-funcionalidade`), com pelo menos 2 commits. Três funcionalidades foram integradas via merge direto no `master` e três via pull request.
